# 🏡 PROPERTY SALES ANALYSIS DASHBOARD
### 📊 Power BI Data Visualization Project

---

## ✨ PROJECT OVERVIEW

The **Property Sales Analysis Dashboard** is an interactive Power BI project designed to analyze property sales data and understand housing market trends.

This dashboard provides insights into property prices, property features, geographical distribution, and average living area through interactive visualizations and key performance indicators (KPIs).

## 🎯 PROJECT OBJECTIVES

- Analyze overall property sales data.
- Identify average and maximum house prices.
- Understand the relationship between property features and prices.
- Explore geographical property distribution.
- Compare property prices based on bedrooms and bathrooms.
- Analyze waterfront and non-waterfront properties.

## 📌 DASHBOARD HIGHLIGHTS

### 1. Key Performance Indicators (KPIs)
- Total Properties
- Maximum House Price
- Average House Price
- Average Living Area

### 2. Geographical Analysis
- Property locations using map visualization.
- Latitude and longitude-based property distribution.
- Property details through map tooltips.

### 3. Property Analysis
- Average price by number of bedrooms.
- Average price by number of bathrooms.
- Average price based on waterfront availability.

### 4. Interactive Filtering
- Living area slicer.
- Dynamic filtering for better data exploration.

## 🛠️ TOOLS & TECHNOLOGIES

- **Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data preparation and transformation.
- **DAX** – Measures and calculations.
- **Data Modeling** – Fact and dimension table structure.

## 🗂️ DATA MODEL

The project follows a dimensional data modeling approach.

**Tables Used:**

1. FactPropertySales
2. DimProperty
3. DimDate

The model supports property sales analysis through fact and dimension tables.
